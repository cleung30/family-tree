# Working conventions

## Merging

Once a PR opened here passes verification (tests, build, and a manual
browser check of the actual change — plus applying any Supabase
migration it needs to the live project), merge it to `main` directly
without waiting to be asked. This was explicitly authorized by the
repo owner (calvin.leung.3@gmail.com) as a standing policy, not a
one-off approval — it applies to future work in this repo, not just
the session it was given in.

This does not extend to anything else conversation-level "always ask
first" guidance would otherwise cover (force-pushes, deleting
branches, rewriting history, etc.) — those still need to be confirmed
each time.
